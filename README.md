# Project Lattice

Official implementation of the paper **"Graph-Structured Retrieval Augmentation for Multi-Hop Question Answering"** (`ORL-2023-009`).

## Repository Status

**✅ Released** — The code accompanying this paper is publicly available under the Apache License 2.0.

## Abstract

We introduce a graph-structured retrieval index that supports multi-hop evidence aggregation for open-domain question answering.

```bash
pip install -r requirements.txt
```
